# Automatización de Datos para Consultoría Ambiental 🌿📊

Landing page personal diseñada para presentar soluciones y servicios especializados de automatización de flujos de trabajo, procesamiento de datos biológicos y generación de entregables técnicos para proyectos ambientales.

🌐 **Sitio Web Oficial:** [https://automatizacion-consultoria.netlify.app/](https://automatizacion-consultoria.netlify.app/)

---

## 🚀 Servicios Presentados

1. **Automatización de Formatos y Anexos de Fauna**:
   - Diligenciamiento masivo de plantillas de campo en Excel (`.xlsm`).
   - Inserción y escalado desatendido de registros fotográficos por taxón.
   - Compilación agrupada en PDF oficial por grupo zoológico.
   - Consolidación de bases de datos y cruce con catálogo biológico.

2. **Dashboard de Gestión de Fauna**:
   - Panel visual interactivo con KPIs de rescate, ahuyentamiento, reubicación y mortalidad.
   - Enlace directo a demostración web funcional en vivo en [Fauna Dashboard](https://fauna-dashboard.netlify.app/).

3. **Reportes Técnicos Automatizados de Fauna**:
   - Flujos reproducibles de análisis ecológico en Python y Quarto/R.
   - Generación paramétrica de gráficos de abundancia y riqueza taxonómica.
   - Tablas jerárquicas estandarizadas con categorías de conservación (UICN, CITES y endemismo).
   - Composición automática de catálogos y anexos fotográficos.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica, accesible y optimizada para SEO.
- **Tailwind CSS (vía CDN)**: Estilizado responsivo con paleta oscura personalizada (`brandDark`, `cardBg`, `accentGreen`, `accentBlue`), efectos glassmorphism y micro-animaciones.
- **JavaScript (Vanilla)**: Desplazamiento suave entre secciones, control de carruseles de capturas e interactividad de visor ampliado (Lightbox modal) para inspeccionar imágenes en máxima resolución sin pérdida de nitidez.
- **Google Fonts**: Tipografía moderna (*Inter*).

## 🌐 Despliegue en Netlify

El proyecto está preparado para publicarse inmediatamente sin requerir pasos de compilación (*zero-config build*):
1. Conecta el repositorio de GitHub a **Netlify**.
2. Deja el campo **Build command** vacío.
3. Configura el **Publish directory** como `.` o déjalo por defecto (ya que `index.html` reside directamente en la raíz).
